북극성 — "세계적 인정"의 조작적 정의와 현재 격차

"세계적으로 인정받는 완벽한 사이트"는 감상이 아니라 측정 가능한 4개 조건으로 정의한다. 이 문서의 모든 고도화 항목은 아래 조건 중 하나 이상에 복무하며, 그렇지 않은 기능은 넣지 않는다.

조건측정 지표 (북극성 KPI)세계 수준 기준현재 상태
① 품질 일관성 — 누가 언제 생성해도 스튜디오급얼굴 유사도 스코어 평균 / 베스트컷 선택률 / 재생성률유사도 0.82+ · 선택률 65%+ · 재생성 15%↓측정 체계 없음
② 운영 속도 — 테마가 곧 상품, 상품 출시가 곧 성장신규 테마 릴리즈 주기 / 프롬프트 개선 리드타임주 2회 릴리즈 · 개선 반영 <24h (무배포)CMS 없음(코드 상수)

1.1

프롬프트 컨트롤 센터 (S12-B) — 본 기획의 핵심

복무: ①품질 ②속도 ③신뢰

이 서비스에서 프롬프트는 설정값이 아니라 재고 자산이자 레시피다. "잘 나오는 프롬프트"가 곧 베스트컷 선택률이고, 선택률이 곧 전환율이다. 따라서 프롬프트는 ⑴ 버전 관리되고 ⑵ 실험으로 검증되고 ⑶ 안전장치 아래에서만 배포되는, 코드와 동급의 배포 단위로 다룬다. 사용자는 끝까지 프롬프트를 보지 못한다(v1.1 원칙 유지) — 통제권은 전부 이 콘솔에 있다.

A. 데이터 모델 — 프롬프트 템플릿의 구조

PromptTemplate { themeId, version: "dol-hanbok@v14", // 테마당 버전 체인, 불변(immutable) status: draft | testing | canary | live | archived, positive: "template with {outfit} {background} {age_style}…", negativeChain: [global.negative, milestone.negative, theme.negative], // 3단 상속 — 글로벌은 편집 시 전 테마 재검증 safetyLayer: LOCKED, // 아동 안전 네거티브 — 콘솔에서 편집 불가, 시스템 강제 주입 variables: { outfit: vocabRef, background: vocabRef, age_style: auto(생일→개월수) }, modelParams: { engine, sampler, steps, cfg, loraWeight, resolution, seedPolicy }, metrics: { bestCutRate, regenRate, hiResConvRate, failRate, costPerCut }, audit: { author, approver, changedAt, diffRef } // 모든 변경 2인 승인 + 감사로그 }

B. 기능 정의

ID기능내용우선순위

PC-08멀티모델 라우팅테마별 생성 엔진 선택(Flux LoRA fine-tune / InstantID zero-shot / 외부 API). 엔진별 파라미터 프리셋, 장애 시 대체 엔진 페일오버, 엔진별 원가·품질 비교 리포트 → 벤더 협상 카드.P1
PC-09성과 대시보드테마×버전 매트릭스로 KPI·원가 한눈에. "선택률 급락" 자동 감지(모델 벤더의 조용한 모델 변경 탐지 목적).P1
PC-10커스텀 컨셉 파이프라인구독자 자연어 요청(v1.1 T-05) → LLM이 내부 템플릿 형식으로 변환 → 안전 린터 통과분만 생성. 반복 요청 패턴은 신규 테마 후보로 자동 큐잉(수요 기반 테마 기획).P2

C. 운영 워크플로 — 프롬프트의 일생

draft 작성·린트→ 플레이그라운드 QA (시드 고정 비교)→ 2인 승인 (4-eyes)→ canary 5% (24~48h)→ A/B 유의성 도달→ live 승격 (무배포 즉시 반영)→ 상시 모니터링 → 열화 감지 시 자동 롤백
안전 불변식 — ⑴ 안전 레이어를 우회하는 경로는 콘솔에 존재하지 않는다(관리자 포함) ⑵ 모든 live 반영은 감사로그에 승인자 2인이 남는다 ⑶ 프롬프트 원문은 사용자 단말로 절대 전송되지 않는다(서버 조립) — 유출 시 모방 서비스에 레시피를 통째로 넘기는 것과 같다.

테마 라이프사이클 CMS (S12-C)

복무: ②속도 ④경제성

"신규 테마 주 2회"(v1.1 운영 원칙)를 사람 손이 아닌 파이프라인으로 보장한다. 테마 = 프롬프트 템플릿(§1.1) + 스토어 메타데이터(이 섹션)의 합성물.

ID기능내용
TC-01라이프사이클 상태기계draft → 내부QA → soft-launch(노출 5%) → GA → seasonal-hold → sunset. 상태 전이마다 체크리스트(샘플 컷 6종·번역·가격·안전 리뷰) 강제.
TC-02시즌 캘린더연간 시즌 맵(설·벚꽃·여름·핼러윈·크리스마스)에 테마를 배치하면 노출 시작/종료·D-n 뱃지·얼리액세스(멤버십)가 자동 스케줄링.
TC-03노출 랭킹 튜너정렬 가중치(시즌>인기>신규) 슬라이더 + 수동 핀(트렌딩 고정). 변경은 즉시 반영·이력 기록.
TC-04테마 단위 가격·프로모션테마별 크레딧 가격, 기간 한정 할인, 번들(마일스톤 패키지) 구성. 쿠폰 코드 발급·사용량 추적.
TC-05현지화 워크벤치테마명·설명·옵션 라벨의 다국어(한/영/일) 관리. 미번역 상태는 해당 로케일에 노출 차단.
TC-06에셋 파이프라인커버 루핑 영상·샘플 컷 업로드 → 자동 트랜스코딩(WebM/MP4, 3해상도)·포스터 추출·CDN 배포. "샘플은 동의받은 모델 컷만" 체크 강제.
운영 지표 — 테마 기획→GA 리드타임(목표 5영업일), 테마별 첫 72h 실행수·전환율로 조기 성과 판정, 하위 10% 테마 분기별 sunset.

운영 대시보드 & CS 콘솔 (S12-A·F·G)

복무: ④경제성
실시간 잡 모니터 (S12-A)

큐 대기 길이, 생성시간 p50/p95, 실패율, 엔진별 헬스. 임계 초과 시 슬랙 경보. "지금 사용자가 몇 초 기다리는가"를 운영자가 항상 안다.

원가·마진 라이브 (S12-G)

외부 API 호출 원가를 잡 단위로 집계 → 잡당 마진, 테마별 손익, 일 원가 예산 소진율. 영상 원가(이미지의 10~30배)는 별도 경보선. 무료 사용자 원가는 CAC로 분류.

퍼널·코호트 (S12-G)

방문→가입→학습완료→첫생성→첫결제 퍼널, 주간 코호트 리텐션, 기념일(백일/돌) 트리거별 전환 기여도. KPI(v1.1 §8)와 1:1 매핑.

사용자 360 & CS 도구 (S12-F)

사용자 검색 → 프로필·잡 이력·크레딧 원장·결제 내역 단일 화면. 크레딧 수동 지급/회수는 사유 코드 필수 + 원장 기록. 실패 잡 원클릭 재실행(사용자 무과금).

사용자 경험 고도화

복무: ①품질 체감 ②전환

3.1 온보딩 — 첫 5분의 마법

  • 실시간 업로드 코치 P0 — 업로드 즉시 클라이언트에서 블러·조도·얼굴 크기 검사, 부족한 각도("옆모습이 없어요") 실시간 안내. 반려를 학습 후가 아닌 업로드 중에.
  • 웰컴 매직 컷 P1 — LoRA 학습(3~10분)을 기다리기 전에 zero-shot 엔진으로 저해상도 1컷을 30초 내 제공 — "된다"는 확신을 먼저 주고 학습을 기다리게 한다.
  • 학습 대기 활용 — 대기 중 테마 위시리스트 담기 → 학습 완료 알림에 위시 테마 딥링크.

3.2 홈·탐색 개인화

  • D-day CRM 저니 P0 — 단발 배너를 넘어 시나리오 설계: D-30 "미리 준비" → D-14 패키지 제안 → D-7 시즌 결합 → D-day 축하 무료 1컷 → D+3 앨범 회고. 카카오 알림톡 템플릿과 1:1 매핑.
  • 추천 랭킹 P1 — 아기 개월수·과거 실행 테마·유사 코호트 행동 기반 개인화 정렬(콜드스타트는 마일스톤 기본 정렬).
  • 검색 고도화 P2 — 동의어("돌복"="한복")·자연어("바다에서 찍은 것 같은") 시맨틱 검색.

3.3 결과·공유 — 바이럴 루프의 완성

  • 공유 랜딩 최적화 P0 — 공유 페이지에 비포/애프터 인터랙션 + "나도 만들기" CTA + OG 이미지 자동 생성. 공유→가입 전환율을 별도 KPI로(목표 8%).
  • 리퍼럴 이중 보상 P1 — 초대자·피초대자 모두 +3컷. 부정 사용(자기 초대) 탐지 규칙 포함.
  • 자동 하이라이트 P1 — 월말 "이번 달의 서연이" 자동 콜라주·릴스용 세로 크롭 제공 — 재방문 트리거.

3.4 기반 품질

  • 성능 예산 P0 — LCP<2.5s·CLS<0.1, 이미지 CDN(AVIF/WebP)+블러 플레이스홀더, 루핑 영상은 뷰포트 진입 시에만 재생(모바일 데이터 배려).
  • 접근성 P1 — WCAG 2.1 AA: 키보드 완주, 스크린리더 라벨, 모션 최소화 설정 존중.
  • 글로벌 P2 — i18n(영/일), 지역별 마일스톤 문화 대응(백일·돌은 한국 고유 → 글로벌은 "100 days"·"1st birthday" 프레이밍), 웹뷰 앱 패키징.
